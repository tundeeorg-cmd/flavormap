# Thai PDF extractor comparison

Generated by `scripts/compare_extractors.py` on 10 DCP documents.
Regenerate rather than editing by hand.

`pdftotext -layout` is not in this comparison: it needs poppler, which is not
installed and cannot be without adding a system package manager to the machine.
`pdfminer.six` is substituted as the third extractor.
